# Cub Scout Pack 127 Calendar Specification

## Overview
This document specifies the creation of a calendar for Cub Scout Pack 127. The pack calendar should be generated at the start of each summer and should follow the example on the first page of
<https://docs.google.com/document/d/10E-W_T7-Wz04ttZoq9v8EV6A43I9H8bmotKo5GuqHfw/edit?pli=1&tab=t.0>

## Program Recommendations
The Calendar should have additional paged with the program recommendation. This is the exact activity that the pack or each den should be doing at each meeting.

## Calendar Details
Generate the calendar as a docx file
This calendar should cover the 2025-2026 Schoolyear and the following summer.
The Calendar filename should be the schoolyear and the words " Pack 127 Calendar" plus the docx extension
The Calendar title should be the schoolyear and the words " Pack 127 Calendar"
The Calendar should have two columns per page
The text should flow from column to column, using a many pages as required
Each entry should be a single event. Try to keep the majority of the event names to the format
Day of Month, Activity, Location
for example
  **2** Pack Meeting (Cabin)
The start of each new month should be recognized, either by putting the name of the month on its own line in bold or by putting an abbreviation for the month in-line with an event. The first and last month of the calendar, and December and January, should include the year.
